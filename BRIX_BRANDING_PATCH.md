# Brix Launcher branding status

The working branch contains custom Brix Launcher branding and user-supplied boxed BL icon assets. The launcher UI and Android icons have been adjusted in source. These changes should be tested in an actual built Android APK/AAB before publication.

This note supersedes earlier planned-patch instructions. Please use [README.md](README.md) for project overview, [BRIX_LEGAL_NOTICE.md](BRIX_LEGAL_NOTICE.md) for attributions and [RELEASE_SAFETY_CHECKLIST.md](RELEASE_SAFETY_CHECKLIST.md) before release.

**Important:** Local developer changes to the application ID, SDK compatibility, Android manifest and signing configuration may not yet be committed to this branch. Do not claim that the repository exactly reproduces a privately built Play Store bundle without a source-to-artifact verification.
